## npm 安装：在网页更新

通过 `npm install -g superhive` 安装、用 `hive start` 启动后台服务的实例，检测到新版后会在底部状态栏出现「有新版本」。点击可查看版本和发布说明摘要；**在运行 Hive 的电脑上打开网页的本机房主**可点「更新并重启」。访客没有更新操作，远程房主设备只显示联系房主的提示，即使该设备已获批管理权限也不能升级服务。

1. 在临时目录安装已确认的 npm 版本，校验包版本、Server / 网页文件和 SQLite 原生依赖。此时旧服务继续运行。
2. 安装成功后替换全局包，用原数据目录和监听配置重启 Server。
3. 页面自动重连并刷新，底部显示新版本。可以关闭更新弹窗继续工作；刷新页面也能恢复更新进度。

Server 必须替换进程，不能只刷新网页使新代码生效。**支持换代交接时，本机 Agent 进程不会下线，手上的任务继续**；不能交接且有人正在执行任务时，网页要求房主确认「等任务完成（推荐）」或「立即更新，中断任务」。不要为了省时间随意选择中断。

安装失败不替换旧包或停止旧 Server。新 Server 重启失败时会恢复旧包并尝试重启旧版本；如果恢复也失败，网页明确显示失败，不会声称服务已恢复。需要排查时查看数据目录的 `web-update.log` 和 `server.log`。更新结果持久保存在 `web-update.json`；重复点击不会启动并行安装。

版本检查缓存一小时，包括离线结果；离线时不会弹报错。发布说明来自项目 GitHub Release，暂不可用时可打开完整发布说明。

## 需要手动更新的情况

| 运行方式                                          | 为什么不能一键更新                                  | 做法                                                                                           |
| ------------------------------------------------- | --------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 源码 / `pnpm dev` / link                          | 不是可替换的 npm 全局包                             | `git pull`、重新构建，按原开发方式重启                                                         |
| `npx` 临时缓存                                    | 没有稳定的全局安装目录                              | `npx superhive@latest restart --data-dir <原数据目录>`                                         |
| npm 全局目录不可写                                | 不能安全替换或回滚包                                | 配置属于自己的 npm 前缀，再执行网页给出的命令；不要用 sudo                                     |
| pnpm / bun / yarn 全局安装                        | 网页的隔离安装与回滚只适用于 npm                    | 在原终端运行 `hive update --data-dir <原数据目录>`                                             |
| `--foreground`、systemd、launchd 或其它进程管理器 | 生命周期归外部管理，不能让 CLI 新起后台实例争抢端口 | 停止原服务、升级包、用原管理器启动，详见[云端部署指南](/guides/cloud-deployment/#7-备份与升级) |
| 桌面客户端                                        | 使用独立的应用更新机制                              | 使用客户端的「有新版本」入口                                                                   |

普通 CLI 后台实例仍可在终端执行：

```bash
hive update --check
hive update --data-dir /path/to/hive-data
```

`--data-dir` 沿用指定目录的服务状态，不会误重启默认目录里的另一个 Hive。数据和消息不会因升级被清空，但更新前仍建议备份；进程交接不等于断电、崩溃或不兼容数据库变更也能无损恢复。

## 桌面客户端

桌面客户端使用自己的应用内更新，不显示 npm 更新按钮。点击「有新版本」查看发布说明，可后台下载并校验，下载好后「重启以更新」。不马上重启也可继续使用，按客户端提示在下次退出或打开时生效；不能应用内更新时退回下载安装包并说明原因。

浏览器里访问桌面客户端的 Server 不会因此获得桌面应用安装权限。
