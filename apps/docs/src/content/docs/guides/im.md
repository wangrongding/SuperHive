## 有什么用

IM 连接让你离开 Hive 网页时仍能给房间发消息、收任务结果。它是 Hive Server 与 IM 平台之间的消息通道，不是把 Agent 安装到手机上：任务仍由接入 Hive 的 Agent 运行。

推荐先用 [快速上手](/start/quickstart/) 确认网页任务能够正常回复，再连接 IM，方便区分 Hive 接入问题和 IM 通道问题。

## 先选择通道

| 能力或边界 | 飞书                             | 个人微信                       |
| ---------- | -------------------------------- | ------------------------------ |
| 接入方式   | 官方开放平台应用，按扫码流程配置 | 腾讯 iLink 通道，需确认风险    |
| 任务通知   | 卡片、状态标签、可用操作按钮     | 文字通知                       |
| 提问作答   | 支持卡片选项等交互               | 通过文字，必要时转到网页       |
| 图片和文件 | 支持双向收发                     | 当前只支持文字                 |
| 适用范围   | 按连接配置使用私聊和支持的群场景 | 只支持本人私聊文字             |
| 默认状态   | 需要主动连接                     | 默认不启用，连接前必须确认风险 |

个人微信没有面向第三方的公开开放平台，此通道可能违反平台规则，有被限制或封号的风险；消息内容会经过微信服务器。不要把它当成官方企业微信集成，也不要用于无法承受账号风险的场景。

## 第一步：从网页连接

![左侧快捷操作的真实界面：新建房间、搜索、提及我、Agent 任务下方是连接 IM。隔离演示界面截图，已裁切去除房间列表。](/media/interface/quick-actions.png)

隔离演示界面截图（裁切），仅展示入口，不是 IM 扫码授权或送达实测。

1. 用房主身份打开网页，在左侧快捷操作点击「连接 IM」。它不在成员面板底部的邀请按钮中。
2. 选择飞书，使用飞书扫码，按页面提示新建或选择应用并确认权限。
3. 如果选择个人微信，先阅读风险提示并勾选确认，再扫码并在手机上确认登录。若管理员禁用了该通道，界面不会提供入口。
4. 等网页显示连接结果，在对应私聊中发送 `/help`。微信需要你先发一条消息，之后才能接收推送。
5. 从 `/room` 或连接设置核对当前房间，避免向错误的项目派任务。

飞书扫码的人作为房主身份发消息。房主登录和绑定账号应由本人操作，不要把二维码发给普通访客代扫，也不要把它当成多人邀请入口。

## 第二步：选房间、选 Agent，再发消息

| 命令                            | 用途                                  |
| ------------------------------- | ------------------------------------- |
| `/help`                         | 查看当前通道支持的操作                |
| `/room`                         | 查看或切换当前发消息的房间            |
| `/who`                          | 查看成员和谁在忙                      |
| `/to`                           | 选择当前房间的默认对话 Agent          |
| `/level`                        | 设置推送档位                          |
| `/scope current` / `/scope all` | 只收当前房间 / 接收本人所在的所有房间 |
| `/lang`                         | 调整 IM 提示语言                      |
| `/web`                          | 在私聊获取网页入口                    |

在飞书中，这些操作也会提供卡片或菜单。为当前房间用 `/to` 选好对象后，不带 `@` 的普通消息可发给它；直接回复某个 Agent 的卡片也能确定接收者。唯一匹配的 `@` 简写可以补全，但第一次使用仍建议核对完整名称。

没有默认对象或明确目标时，房间的主 Agent 规则可能接管。不要在普通句子中随便提一个近似名字来试探路由，先用 `/to` 或明确 `@`。

## 第三步：配置推送，处理任务通知

推送档位包括「与我相关」「IM 任务」「全部 Agent」「全部消息」。接收范围默认覆盖本人所在的所有房间，可用 `/scope current` 收窄。收通知的范围与发送消息的当前房间是两件事。

| 档位             | 推送内容与频率                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------------ |
| 与我相关（默认） | 本人任务的最终结果、问本人的问题、提到本人、失败或需要处理的状态；即时推送，条数随任务量变化。         |
| IM 任务与提及    | 从 IM 发起的任务回复和进度、提到本人的消息；本人任务的最终结果和异常提醒仍保留。                       |
| 全部 Agent       | 与本人相关的即时推送，其余给人看的 Agent 发言每个房间约每 3 分钟合并。                                 |
| 全部消息         | 默认房间中其他人类成员的话和 Agent 给人看的回复每 3 分钟合并；提到本人、提问和需要处理的通知即时推送。 |

**所有档位都过滤噪音**：定时任务到点时给 Agent 的触发备忘（`kind=schedule`）、本人在网页或其它渠道发话的回显、Agent 内部派活及回执（提到本人除外）、Agent 互相回复、不是本人发起的任务的进度。定时任务的创建确认、真正的结果、结果未知和需要人回答的问题不是触发备忘，仍按任务通知规则推送；不会取消或停止定时任务。

「全部消息」加「所有房间」不再等于把每个房间都复制到同一条 IM 私聊：**其它房间默认仅推与本人相关的消息**。确实需要查看其它房间全部普通消息时，在连接设置中打开「其它房间也推全部」（旧连接也默认关闭）；它只影响「全部消息」档，不扩大接收范围。跨房间摘要仍保留房间名和切换入口。

普通消息合并后，每个持续活跃的房间约每小时 20 张摘要卡片（微信为文字摘要），而不是每条消息一条通知。空窗口不发；长消息可能拆成多条，@ 本人、提问、任务结果、异常和附件另计，因此不是总推送量的硬上限。想最安静时优先用「与我相关」，必要时再选「仅默认房间」。

- 飞书卡片会标出房间与发送者，并区分进度、结果、失败、结果未知和待批准等状态。
- 本人任务的中途进度也可能推送；进度说明不是最终完成证明。
- 支持的卡片可以直接回答选项、批准、重试或继续；操作仍经过 Hive 权限和任务状态校验。
- 回复跨房间的卡片会发到卡片所属房间，不能仅凭自己当前的 `/room` 判断回复位置。
- 微信用文字表达这些信息；不能操作的交互转到网页完成。

为了避免重复提醒，连接 IM 后可把网页「设置 → 通知 → 任务提醒」设为「只在页面内」。这个设置不会关闭 IM 推送。

![IM 流程示意：手机消息进入 Hive 房间，由 Agent 所在电脑处理，任务记录再通过飞书卡片或微信文字推送](/media/codex2/im-flow.svg)

这是原创消息通道示意，不是飞书或微信截图。IM 连接和房主设备登录都不意味着手机拥有 Server 电脑的终端权限；管理电脑还需要相应授权。任务最终在 Agent 所在电脑执行。

## 网页登录票和附件边界

飞书私聊中的「在网页查看」或 `/web` 入口可以带一次性房主登录票，24 小时内有效。需要在另一设备登录时重新获取，不能复用已经消费的票，也不要转发给别人。群卡片不带房主登录票；群里的 `/web` 不提供私聊登录入口。

飞书支持图片和文件双向收发，具体仍受附件格式、大小、平台接口及 Runtime 读取能力约束。微信当前只有文字；要上传或下载文件，请到 [网页附件功能](/guides/messaging/#上传图片或文件)。

## 注意事项与排查

- Server 和 Agent 必须保持可达。扫码成功不代表电脑睡眠后仍能接单；「设置 → 这台电脑」的保持在线功能在支持系统和满足电源策略时阻止空闲睡眠，不保证合盖仍在线。
- 收不到通知时先看网页 IM 状态、推送档位和接收范围；微信先检查是否发过一条私聊消息，连接失效时按网页提示重新登录。
- 用 `HIVE_IM_WECHAT=0` 启动 Server 可整体关闭微信通道；这不是在 IM 里发送的命令。
- IM 消息和附件会经过对应平台，不要发送凭据或不允许外传的资料。绑定撤销、房主设备授权等安全边界见 [权限指南](/guides/permissions/) 和 [安全参考](/reference/security/)。
- 本页按当前源码描述能力，未扫描真实二维码、操作真实应用授权或验证平台送达；实际问题见 [排障指南](/reference/troubleshooting/)。
