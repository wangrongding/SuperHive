# 底部状态栏调研（rd #6405）

> 结论：做一条 24px 高、低对比的底部状态栏，左边放「现在怎么样」（连接、Agent、主 Agent、故障、IM），右边放「我常改的」（代理、熄屏保持在线、通知、发送方式、外观）。每项点开是向上弹出的小面板，直接改，改的就是设置页同一份状态；在「设置 · 外观」或外观菜单里可以关掉；窄于 720px 不显示。

## 1. 参考了什么

### Orca（本机 `/Applications/Orca.app` 1.4.274，只读看了打包后的前端代码和文案）

Orca 的状态栏是窗口底部一条约 26px（`h-6.5`）的细条，由一个个「segment」组成，几乎都是**状态 + 点开的小面板**：

| segment                                                  | 显示                                                     | 点开                                   |
| -------------------------------------------------------- | -------------------------------------------------------- | -------------------------------------- |
| 各家订阅用量（Claude / Codex / Gemini / Cursor / Kimi…） | 用量百分比小条、重置倒计时                               | 账号列表、切换账号、已用/剩余切换      |
| Caffeinate（防睡眠）                                     | Active / Inactive                                        | Auto（Agent 工作时保持唤醒）/ On / Off |
| Ports                                                    | 工作区端口数                                             | 端口和进程列表                         |
| Resource Manager                                         | 内存、终端会话数、孤儿进程数                             | 按工作区分组的终端，可结束孤儿进程     |
| SSH 主机                                                 | 已连主机数                                               | 搜索、切换主机                         |
| Agent 恢复 / Skill 更新 / 远程 Server 更新               | 只在有事时出现（「3 agents to resume」「Updating 2/5」） | 详情和重试                             |
| Git blame                                                | 光标行最后改动者                                         | —                                      |

几个值得学的做法：

- **只在有事时出现**：恢复、更新、失败这类 segment 平时不占位置。
- **每项有 aria-label 写全**（`{{title}}, {{status}}`），栏上的字可以很短。
- **可配置**：「设置 · 外观」里逐项开关显示哪些指示器（`statusBarDescription: Choose which indicators appear in the status bar.`），插件也能往状态栏加项。
- 防睡眠的 Auto 模式（Agent 工作时保持唤醒）和我们的「熄屏后保持在线」几乎一样，Orca 把它放在状态栏，我们藏在「设置 · 这台电脑」里。

### VS Code / JetBrains

- 22px 高，左边是工作区级状态（分支、同步、问题数），右边是编辑器级/偏好（编码、缩进、语言模式、通知铃铛）。
- 每项一个点击动作：要么打开快速选择（改设置），要么打开相关面板；不在栏上直接放开关控件。
- 右键状态栏可以逐项隐藏；`View › Appearance › Status Bar` 可整条关掉。
- 窄时从左往右按优先级截断。

## 2. 我们藏得深、适合上栏的项

| 项                    | 原来在哪                   | 栏上                         | 点开                                                              |
| --------------------- | -------------------------- | ---------------------------- | ----------------------------------------------------------------- |
| Hive 连接 + 版本      | 只有断线时顶部横幅         | 绿/黄/红点 + Hive 名 + 版本  | 地址、版本和提交、运行方式；断线时说明会自动重连                  |
| 客户端新版本          | 左栏底部                   | 有新版才出现                 | 沿用原来的更新弹窗                                                |
| 在线 / 忙碌 Agent 数  | 成员列表里数               | `5 在线 · 2 忙`              | 打开「Agent 任务」活动面板                                        |
| 主 Agent 模型、上下文 | 成员详情卡片里             | 名字 · 模型 · 上下文 %       | 状态、模型和 effort、上下文用量条、缓存说明（与成员卡同一份文案） |
| 未处理故障            | 左栏「故障」               | 有才出现，`3 个故障`         | 打开故障面板                                                      |
| IM 连接               | 顶栏 IM 弹窗里             | 已连渠道 / 需要处理 / 已暂停 | 打开 IM 弹窗                                                      |
| 网络代理              | 设置 · 这台电脑 · 网络代理 | `代理：跟随系统`             | 跟随系统 / 手动 / 不用代理；地址和例外跳设置页                    |
| 熄屏后保持在线        | 设置 · 这台电脑            | `保持在线中` / `会睡眠`      | 两个开关（连着 IM 时、执行任务时）；用电池时等更多跳设置          |
| 消息通知              | 设置 · 通知                | `@ 我时通知`                 | 关 / @ 我时 / 全部                                                |
| 发送方式              | 设置 · 聊天                | `⌘ Enter 发送`               | 组合键 / Enter                                                    |
| 主题、密度、语言      | 设置 · 外观                | 主题图标 + 名字              | 三组单选；隐藏状态栏                                              |

**没放的**：

- 工作区分支 / 任务目录数：顶栏已经有分支下拉和「管理任务目录」，栏上再放一份是重复。
- 订阅用量：我们的用量页按房间算钱，跟 Orca 那种「这个账号还剩多少」不是一回事，等有了账号额度数据再加。
- 逐项隐藏：先做整条开关，项不多、而且大部分只在有事时出现；以后插件第一阶段做完再一起做「选择显示哪些项」。

## 3. 设计约束和做法

- **样子**：高 24px，`--bg-sidebar` 底、顶部一条 `--border-light`，11.5px `--text-tertiary` 字；状态色只用在小圆点和需要处理的项上。深浅色都用现有设计 token，不新增颜色。
- **和设置页同步**：栏上改的都是 App 里同一份 state，写同一个 localStorage key / 调同一个本机接口（代理 `networkProxy/updateNetworkProxy`，熄屏 `updateKeepAwake`，通知 `updateMessageNotifications` 会照常申请系统通知权限）。代理是 Server 上的设置，设置弹窗关上时重新拉一次。
- **弹出面板**：portal 到 body、`position: fixed` 贴在按钮上方，右半边的项右对齐防止出屏；`role="dialog"` + 标题；打开后焦点落在当前选中项，↑↓/Home/End 移动，Esc 和点外面关掉，Esc 把焦点还给按钮；尊重「减少动态效果」。
- **权限**：代理、熄屏只给这台电脑上能管理本机的房主（`local.enabled && local.canManage`）；IM 只给房主且不是沙箱；故障按原来的 `incidentsAvailable`；访客只看到连接、Agent 数、主 Agent、通知、发送方式、外观——都是只跟自己有关或只读的。
- **窄屏**：用容器查询逐级收：≤1100px 去掉文字说明和主 Agent 的模型，≤900px 右边只剩图标，≤640px 去掉主 Agent 和发送方式；≤720px 视口（手机）整条不显示，这些设置都还在「设置」里。
- **桌面端**：状态栏在 `.app-shell` 这个纵向 flex 的最底下，不碰标题栏和红绿灯区域。
- **关掉**：「设置 · 外观 · 显示底部状态栏」，或外观菜单最下面「隐藏状态栏」；存在 `superhive.status-bar`，默认开。
